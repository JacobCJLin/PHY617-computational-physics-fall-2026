## Course Description

This course introduces classical simulation algorithms for quantum mechanics, organized around three computational methods: exact diagonalization (ED), matrix product states (MPS), and Heisenberg-picture/Pauli propagation. Each method is introduced in a general framework, with applications to ground-state problems, quantum dynamics, and quantum circuit simulation. AI-assisted coding is strongly encouraged and will be discussed throughout the course.

The course is designed to be interactive, so please bring your laptop. The lectures are structured roughly as follows: I will present the core concepts and algorithms, and then you will work on exercises in the in-class notebooks, labeled as NB.

The homework notebooks (labeled as HW) apply these algorithms to physics problems. The exercises in the NB notebooks are designed to help you build up the code needed to solve the HW problems.

You are strongly encouraged to use AI tools and existing software packages when working on the homework problems and in-class notebooks.

We have two lectures reserved as buffer days or for special topics. If there are any topics related to the course that you think would be interesting to discuss, please send me your suggestions before September 18. Examples include fermionic systems, open quantum systems, quantum simulation algorithms or others.

## AI Policy
You are strongly encouraged to use AI tools to assist with coding in this course. We will discuss AI-assited coding throughout the course. However, AI should be used in a way that does not “cheat” yourself out of learning. You should therefore make sure that you understand the code you submit and are able to explain what it does, why it works, and how it relates to the algorithms discussed in class.
